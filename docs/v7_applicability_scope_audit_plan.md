# v7 적용범위 독립 감사 계획

작성: 2026-09-11, dev / mac

## 질문

현재 card v7은 `v6의 지방 소액수의 적용 유형`을 선행조건으로 둔다. 그러나 주최 측
항목표는 국가계약법 시행규칙 제25조와 지방계약법 시행규칙 제25조를 모두 근거로 들며,
별도로 `지방 + 소액수의 가능`이라고 적는다. 이 비고가 v7의 전체 적용 전제인지,
인접 지역 확대를 별도로 허용할 수 있는 계약영역을 뜻하는지 원문으로 확정한다.

## 출처와 독립 판정 기준

- 국가계약 시행규칙 제25조제3항은 제한경쟁의 소재지 제한을 현장·납품지가 있는
  시·도 관할구역으로 두고, 현장·납품지가 인접 시·도에 걸치거나 해당 지역의 적격자가
  10인 미만인 경우에 인접 시·도를 포함할 수 있게 한다.
- 지방계약 시행규칙 제25조제3항도 제한입찰의 소재지 범위를 시·도 관할구역으로 두고,
  현장이 걸친 경우, 인접 지역에 납품지·관리시설이 있는 경우, 적격자가 10인 미만인
  경우에 인접 시·도를 포함할 수 있게 한다.
- 지방 수의계약 운영요령은 2인 이상 견적 수의계약에서 관할 시·군과 인접 시·군·자치구,
  또는 관할 시·도와 인접 시·도를 포함하는 제한을 명시적으로 허용한다.

따라서 `지방 소액수의`는 v7 전체의 선행조건이 아니라 인접 확대가 허용될 수 있는 별도
계약영역이다. 국가·지방 제한입찰의 일반 규정과 지방 소액수의 허용을 분리해야 한다.

## 최소 변경

1. 고시금액 미만인지 확인한다.
2. 두 개 이상 지역명이 실제 참가자격 범위를 뜻하는지 확인한다.
3. 현장·납품지의 기준 지역에 인접 지역을 더한 관계인지 확인한다.
4. 적용 계약법·계약방법에서 그 확대를 허용하는 열거 사유가 실제로 충족됐는지 확인한다.
5. 지방 2인 이상 견적 수의계약의 명시적 허용 범위이면 0으로 판정한다.

지역명 나열, 납품지·사업장 위치 설명, 서로 인접한지 불명인 지역 묶음, 고시금액 미만 여부
또는 허용 사유가 불명인 경우는 0으로 유지한다. Python은 지역의 인접성이나 최종 label을
계산하지 않는다.

## 실험 통제

- `decision_cards_v9_v6_scope.json`을 base로 v7 card만 바꾼 새 artifact를 만든다.
- 첫 ablation은 `prompt.decision_cards_path`만 변경한다.
- 제품 조건·익명화 규약·source scope·merge·모델 파라미터를 동시에 바꾸지 않는다.
- exact rendered span, source coverage, tokenizer admission, mock, semantic contract,
  preflight를 통과한 뒤 fast20에서 v7 동일-ID 효과를 평가한다.
- dev label은 카드 수정의 출처가 아니며, 원문 감사를 끝낸 뒤 일치 여부만 대조한다.
