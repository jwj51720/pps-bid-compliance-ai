경쟁제품/일반제품 구분은 항목표 v18의 `일반물품` 범위와 제공 제품 CSV의 actual-target
대조에서 온다. exact code presence는 적용확정이 아니며 unknown은 비경쟁 증명이 아니다.
필수 자격확인서의 위치/역할 구분은 위 제한경쟁의 실질을 원문에서 확인하기 위한 읽기 지시다.
확인서가 특정 heading 밖에 있다는 이유로 무시하거나 Python presence rule로 계산하지 않는다.

전체 문서 absence는 현행 pipeline의 frozen per-pass AND 계약이다. 적용불명과 진정한 부재가
같은 binary 출력에 섞이는 위험을 별도 audit하지만 이 실험에서 merge를 바꾸지 않는다.
e18 blank는 주최 측 evidence-exempt 항목 계약에서 온다.
