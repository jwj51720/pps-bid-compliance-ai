# v6 적용범위 독립 감사 계획

작성: 2026-09-11, dev / mac

## 질문

현재 card v6은 `지방계약의 고시금액 미만 2인 이상 견적 수의계약`을 선행 적용유형으로
둔다. 주최 측 항목표의 v6은 국가계약법 시행규칙 제25조와 지방계약법 시행규칙 제25조를
모두 근거로 들고, `지방 + 소액수의 가능`을 비고로 둔다. 이 비고가 전체 적용 전제인지,
시·군·구 제한을 예외적으로 허용하는 별도 경우인지 원문으로 확정한다.

## 현재 확인된 원문

- 국가계약 시행규칙 제25조제3항: 제한경쟁의 소재지 제한은 원칙적으로 현장·납품지가 있는
  시·도의 관할구역이며, 열거된 경우에만 인접 시·도를 포함할 수 있다.
- 지방계약 시행규칙 제25조제3항: 제한입찰의 소재지 제한도 원칙적으로 현장·납품지가 있는
  시·도 관할구역이며, 열거된 경우에만 인접 시·도를 포함할 수 있다.
- 주최 측 항목표는 위 국가·지방 제한입찰 조문을 v6의 공식 reference로 직접 지정한다.
- 별도의 수의계약 기준에는 일정 요건에서 시·군 단위 제한을 허용하는 규정이 있다.

따라서 현재까지의 출처는 `지방 소액수의만 v6 적용대상`이라는 카드 문장을 지지하지 않는다.
오히려 국가·지방 제한입찰의 기본 시·도 범위와, 수의계약의 더 좁은 지역 허용을 분리하는
해석을 지지한다.

## 수정 원칙

첫 card 실험은 v6 한 항목만 바꾼다. v7·v8로 동시에 일반화하지 않는다. 새 문장은 다음
truth condition을 명시해야 한다.

1. 고시금액 미만 공고에서 소재지 조건이 실제 참가자격인지 확인한다.
2. 국가·지방 제한입찰은 원칙적인 시·도 범위보다 좁은 시·군·구 제한이면 v6 후보이다.
3. 지방/국가 소액수의 등에서 시·군 단위 제한을 허용하는 명시적 요건이 충족되면 0이다.
4. 현장·납품지 설명, 지역명 나열, 계약유형·금액·제한 단위가 불명확한 경우는 0이다.

## 검증과 통제

- 새 versioned card artifact를 만들고 source hash를 보존한다.
- base는 EXP169/170/172의 card v6이며 `prompt.decision_cards_path`만 변경한다.
- 제품 조건 전달 실험과 결합하지 않는다.
- v6 gold 양성/음성에서 원문·metadata를 사람이 독립 검토한 작은 dossier를 먼저 만든다.
- exact rendered v6 card span, source coverage, tokenizer admission, mock, semantic contract,
  preflight를 통과한 뒤 fast20 → holdout20 → dev200 순서로 평가한다.
- dev label은 카드 문구의 출처가 아니다. 공식 원문과 충돌하는 dev 사례는 별도로 기록한다.
