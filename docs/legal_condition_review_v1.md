# v1~v24 법령 조건 검토표

이 표는 dev label·공고 ID·오류 사례를 사용하지 않는다. `항목표.json`과 대회 제공 법령 package만으로
만든 모델용 요약의 검토 기준이다. 각 행에서 적힌 source chunk의 **원문 전체**는
`data/derived/legal_condition_ledger_v1.json`에 보존된다. 따라서 아래의 짧은 문장이 판단에 필요한
조건을 빠뜨렸다고 판단되면, 원문을 다시 읽어 요약과 ledger를 함께 고친다.

## 검토 완료 기준

각 행은 다음 네 가지를 만족해야만 `reviewed`로 승격한다.

1. 원문 selector가 정확한 장·절·조문을 가리킨다.
2. 적용 전제, 위반 경계, 0 예외·단서, 수치·기간·비율이 모두 표 또는 대응 요약에 있다.
3. 모델용 16개 bundle에 해당 행의 요약만 들어가며 다른 v의 규칙은 들어가지 않는다.
4. Gemma tokenizer로 고정문맥과 문서가 함께 admission을 통과한다.
