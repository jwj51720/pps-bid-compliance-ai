# INC-071: Audited-Card Mechanism Pilot

INC-070 did not justify an invented all-24 card set: only 11 cards survived a
separate source-only audit.  This experiment isolates whether those accepted
cards help semantic legal judgment.

Each arm receives the same metadata, every complete ordered source document,
same 11 nested `v/e` cells, model, seed, and output reserve.  Treatment adds
only the 11 accepted short cards.  The cards are explicitly non-evidence; a
positive non-absence cell without an unchanged source substring is downgraded.

The deterministic 32-notice cohort contains one hash-selected positive per
target item and then 21 hash-selected remaining notices.  Thirty-two is a
coverage/false-positive design (11 target-positive anchors plus comparison
notices), not a score-selected quantity.  Two repeats per arm make 128 calls,
with a `$0.55` ceiling.

Advance only when both repeated card-minus-control Macro-F1 deltas are
positive, corrected cells outnumber new errors, and no item loses every cohort
true positive.  A pass authorizes an all-dev confirmation; a failure rejects
global injection and leaves the cards available only as controlled vocabulary
for a later e-prime extraction study.
