# INC-031: Metadata-State Audit Result

No organizer-metadata state family is authorized as an automatic label rule.

The low-cardinality procurement-regime and joint-contract families leave every
or nearly every positive in a state also containing negatives. The exact
organizer-clause family has the same result for 20/24 labels. The higher
cardinality restriction-flag family has apparent dev-exclusive positive states
for some items, but only because 103 exact states fragment the 200 notices;
its best coverage is 60% and cannot establish an unseen-state rule.

Raw amount fields were deliberately not binned, so no dev-derived numerical
threshold was introduced. The audit therefore rejects metadata-only prediction
and preserves metadata solely as a factual applicability input.

An orthogonal observation from INC-030 changes the next test: its no-law
four-item control has target Macro F1 0.30948, whereas the same four labels in
the historical global INC-018 output each had F1 0. This does not prove an
output-group policy because it is confounded with a different request run and
provider variation. INC-032 will repeat that no-law group exactly before any
composition with the 24-label baseline is considered.
