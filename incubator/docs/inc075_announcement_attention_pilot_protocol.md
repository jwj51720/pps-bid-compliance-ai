# INC-075: Announcement Attention for v7/v23

INC-074 establishes that every positive organizer evidence substring for v7
and v23 is nonempty and occurs in the announcement.  This experiment tests
whether that source locality helps decision quality, without claiming that
other documents are irrelevant to final compliance.

The full arm receives all complete documents; the attention arm receives only
the complete announcement.  Both have the same metadata, system contract,
two items, model, output schema, and evidence validator.  A final schedule
could retain a mandatory full-notice call and use the announcement pass only
as a targeted second opinion, so this pilot does not violate full-document
coverage requirements.

The 24-notice cohort contains one deterministic positive anchor per item plus
22 independent hash-selected comparisons. Two repeats make 96 calls. Advance
only if both announcement-minus-full deltas are positive with no recall loss.
