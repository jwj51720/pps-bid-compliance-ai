# INC-047 Result: v9 Product-Identifier Facts

The document-type-independent typography audit covers all six v9 positives,
including notices and specifications. It is nevertheless unusable as an
automatic candidate gate: 95.4% of v9 negatives contain at least one such
identifier form, largely because Latin-plus-digit strings are ubiquitous in
technical procurement documents.

Decision: do not expand a brand/model keyword dictionary from dev cases. A
future v9 method needs a source-grounded distinction between binding named
specification and descriptive/equivalent-product language; simple identifier
presence, document type, or generic English token count is not that distinction.
