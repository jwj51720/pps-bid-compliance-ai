# 나라장터 자체입찰 공고 법령 위반사항 모니터링 AI 경진대회

2026년 [DACON 나라장터 자체입찰 공고 법령 위반사항 모니터링 AI 경진대회](https://dacon.io/competitions/official/236754/overview/description) 참가 기록. 입찰공고의 법령 위반 가능성을 찾아내는 추론 파이프라인을 설계하고, 제출 결과와 실패 원인을 정리했다.

## Overview

- **입력:** 공고문·첨부 문서·나라장터 등록 정보.
- **출력:** 24개 검토 항목의 위반 여부(0/1)와 원문 근거 문구.
- **제약:** 모든 참가자가 고정된 Gemma 4 26B A4B IT 사용. 추가 학습 불가, 제출 코드 추론시간 2시간 제한.
- **평가:** 24개 항목의 양성 F1 평균. 근거 문구는 리더보드와 별도로 정성평가. [대회 평가 기준](https://dacon.io/competitions/official/236754/overview/evaluation)

## Approach

- **초기:** 문서 분할·결과 병합, 판단 카드, 제품 정보, 사실 발췌, 항목 그룹화 실험. 문서 조각과 항목 그룹의 곱으로 호출량이 늘면서 시간 초과 반복.
- **후기:** 공유받은 참고 구현의 아이디어를 분석하고 `src/pps_ai`로 재구성. 금액·날짜·제품 코드·자격요건을 원문 출처가 확인되는 사실 후보로 정리하고, 항목별 최종 판정 주체를 명시. Gemma 판단과 Python의 관계 계산·원문 근거 검증을 조합. [구현 기록](docs/clean_reference_l41_dev200_result.md)

## Findings

- **구조적 전환의 효과:** 최고 공개 점수는 S001의 **0.6054**. 이전 최고 EXP123의 0.2604에서 상승. 구조화된 사실 후보와 항목별 판정 주체가 가장 큰 성능 변화를 동반했다.
- **일반화 격차:** S001의 로컬 0.8151 대비 공개 0.6054. 작은 dev200을 반복 사용하며 선택한 규칙, 평가 공고의 분포 차이, 로컬 API와 평가 서버의 생성 차이는 가능한 원인. 현재 결과만으로 기여도를 분리할 수 없다. [상세 진단](docs/s001_public_generalization_diagnosis_20260923.md)
- **단일 항목 교체의 한계:** S027에서 v3 전용 판정을 제거했지만 공개 점수는 0.5800으로 하락. 한 항목의 로컬 오류 분석만으로 전체 일반화 문제를 해결할 수 없었다.
- **실행시간:** 문서 분할과 항목 그룹화를 함께 적용한 제출들은 2시간 제한을 넘었다. 배치 크기보다 실제 Gemma 호출 수와 입력 길이를 먼저 계산해야 한다. [제출·실행 기록](docs/submission_lessons.md)

## Recommendations

- 개발용 오류 분석과 일반화 검증을 분리하고, 정책 선택에 쓰지 않은 평가 집합 확보.
- 공고 문장의 역할과 출처를 확인한 뒤 사실 후보로 구조화. 항목별 진리조건에 맞춰 한 변경씩 비교.
- 제출 전 입력 누락·원문 근거·호출량을 확인하고, 평가 환경에 가까운 조건에서 추론시간 측정.
